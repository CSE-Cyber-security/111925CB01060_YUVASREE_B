# Daily Expenses Tracker 💰

A simple Python-based Daily Expenses Tracker that helps users record, view, and calculate their daily expenses.

### Features
- Add daily expenses
- View all recorded expenses
- Calculate total expenses
- Simple menu-driven interface
- Beginner-friendly Python project

### Technologies Used
- Python
- Lists
- Loops
- Conditional Statements

**Purpose:** To manage daily spending and track expenses easily using Python.
